# Project Context

## Purpose

アプリ/Web開発で繰り返し発生する判断・実装を、再利用可能でテスト可能な標準・テンプレートとして管理し、将来的にAI対話から選択・組み立てられる開発基盤を作る。

## Scope

Feature → Pattern → Standard → Template → Variant のモデルで開発標準、設計思想、実装テンプレート、AI選択フローを整備する。

## Current Knowledge

- Public repository。
- AI変更時は `AI_RULES.md` が必須ルール。
- Authentication が最初のProof of Concept。
- `docs/philosophy.md`, `docs/architecture.md`, `docs/repository-structure.md`, `docs/contribution.md` が主要設計資料。

## Constraints

機密情報、顧客/勤務先固有情報、個人情報、認証情報をコミットしない。
