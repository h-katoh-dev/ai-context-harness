# Project Context

## Purpose

システムアーキテクチャの判断力を実践的に身につける公開ナレッジベース。

## Scope

責務・境界、複数案、トレードオフ、セキュリティ、信頼性、スケーラビリティ、保守性、運用性、既存構成レビュー、ADRを扱う。

## Current Knowledge

- 「何を使うか」より「なぜ選ぶか」を重視。
- Learning Loop: Requirement → Responsibilities/Boundaries → Options → Trade-offs → Decision → Review → ADR。
- `principles/`, `patterns/`, `exercises/`, `case-studies/`, `architecture-reviews/`, `adr/` が主要構造。
- `dev-standard` は実装標準、`architecture-playbook` はアーキテクチャ判断と役割分担する。

## Constraints

Public repository。機密・顧客/勤務先固有情報・個人情報・credentials/secrets/tokens/private URL・未公開案件情報を保存しない。
