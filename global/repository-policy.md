# Repository Visibility Policy

AI Context Harness 自体は、一般公開可能な「AI開発コンテキスト管理の仕組み」として Public で管理する。

## Public Repository の原則

Public に保存する情報は、以下をすべて満たすこと。

- 一般公開を目的とした知識・技術・学習成果である
- 個人情報・秘密情報・顧客情報・勤務先の非公開情報を含まない
- README やコードから個人固有の機密情報を推測できない
- 公開されることを前提にレビューされている

## Private に分離するもの

以下は AI Context Harness の Public リポジトリには保存しない。

- 個人の職務経歴・転職活動・求人監視
- 投資判断、資産・取引に関する情報
- 企業アイデア、事業構想、未公開の企画
- 個人利用に依存する継続コンテキスト
- 個人情報、秘密情報、顧客情報、勤務先の非公開情報
- その他、公開を前提としていない個人的なプロジェクト情報

これらは別の Private リポジトリまたはローカル環境で管理する。

## Context の公開境界

Public Harness には、再利用可能なルール・テンプレート・一般化されたサンプルのみを置く。
個別プロジェクトの Context は、そのプロジェクト自体が Public かつ内容が公開可能である場合のみ登録する。

## 絶対ルール

1. 迷った場合は Private を選択する。
2. Public 化は「公開しても問題ない」ことを確認した後に行う。
3. リポジトリの Visibility だけでなく、コミットするファイル単位でも公開可能性を確認する。
4. Public リポジトリには secrets / credentials / personal data / confidential information を保存しない。
5. Public 化する場合は、過去の Git 履歴にも公開できない情報が残っていないことを確認する。
6. 個人利用の継続コンテキストは Public Harness に混在させない。
